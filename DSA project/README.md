To run this program:

1. go to terminal then write "uv run fastapi dev"
2. copy the domain that it generated in the terminal it should look like this -> ("http://127.0.0.1:8000")
3. paste the domain on ur browser

*note: other ways to run this is just do the first step, then open your browser then
type http://localhost:8000 (to test and view the documentation add this path/endpont in the domain "/docs")

*if you encountered an error after performing the commandline
try "uv init" to initialize the project then try it again.

Example:
    http://127.0.0.1:8000/
    http://localhost:8000/docs
